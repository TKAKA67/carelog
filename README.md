# CareLog

Pleos Connect용 차량 정비·관리 이력 앱입니다.
2026 현대자동차그룹 차량용 앱 개발 공모전 출품작.

차가 실제 주행 데이터로 운행 조건을 판단해서 정비 항목별로 언제 무엇을 하면 되는지 알려주고,
정비한 내용을 차에 기록해 두었다가 차를 팔 때 케어 패스포트로 넘겨줍니다.

## 왜 만들었나

현대차 매뉴얼에는 정비 주기가 일반 조건 / 가혹 조건 두 가지로 나와 있습니다.
가혹 조건을 "자주" 겪으면 엔진오일 주기가 절반이 되는데, "자주"가 어느 정도인지는 정의가 없습니다.
그래서 대부분 감이나 5,000km 관행으로 정비하고, 그렇게 관리한 기록도 정비소·영수증마다 흩어져서
막상 차를 팔 때는 증명할 방법이 없습니다.

## 기능

| 화면 | 내용 |
|---|---|
| 정비 권장 | 항목별 남은 거리, 권장 기한, 예상 시기. 일반/가혹 판정 근거 표시 |
| 운행 | 실시간 주행 값, 최근 30일 운행 조건 비율(정체·단거리·공회전·고속·산길·급가감속), 최근 트립 |
| 정비 기록 | "엔진오일 갈았어" 음성 기록, 정비소 확인 QR, 기록 신뢰 등급(정비소 확인 / 차량 기록 / 차주 입력) |
| 판매 준비 | 기록 완성도, 판매 전 권장 정비, 케어 패스포트 공유 QR |
| 인계 모드 | 구매자 질문에 차가 기록으로 답변, 명의 이전 후 새 차주에게 기록 승계 |

판정 규칙
- 최근 30일 주행거리 중 해당 조건 비율이 30% 이상이면 "자주"로 봅니다. (매뉴얼에 정의가 없어서 정한 기준이고, 화면에 그대로 보여줍니다)
- 출력은 매뉴얼의 두 주기 중 하나뿐입니다. 중간값을 만들지 않습니다.
- 기록이 부족하거나 기준 ±5%p 이내면 가혹 주기로 권장합니다.
- 엔진오일 레벨 경고 등 차량 경고가 있으면 다른 계산보다 먼저 안내합니다.

## 구조

```
app/src/main/java/com/tk/carelog
├── engine/     매뉴얼 주기표, 트립 요약, 판정 엔진
├── data/       저장소(JSON), Repository, 패스포트 통계
├── vehicle/    Pleos Vehicle SDK 래퍼, AAOS 차속·기어
├── service/    주행 기록 서비스, 부팅 시 자동 시작
├── voice/      음성 안내 (TTS)
├── demo/       시연 주행 / 시연 데이터
└── ui/         화면 (Jetpack Compose)
```

경로나 좌표는 저장하지 않습니다. 트립마다 조건별 거리만 남깁니다.

## 사용 SDK

| SDK | 용도 |
|---|---|
| Vehicle SDK — Odometer | 총 주행거리, 트립 거리 |
| Vehicle SDK — Safety | 엔진오일 레벨 상태, 경고등 |
| Vehicle SDK — CarInfo | 차종 확인 (예정) |
| AAOS 차량 속성 | 차속, 기어 |
| NaviHelper | 정비소 경유 제안 (예정) |
| TTS / STT | Pleos SDK 공개 전까지 Android 기본 API 사용 |

## 실행

1. Android Studio에 Pleos Connect Emulator(v2.1.0, API 34) 설치 후 AVD 생성
2. 에뮬레이터 부팅 후 `setup_devbox.bat` 실행 (프로젝트 CRN 등록)
3. `local.properties`에 Pleos 키 추가

```
pleos.clientId=...
pleos.clientSecret=...
```

4. Run

## 시연 순서

1. 운행 → `도심 출퇴근 1주` : 첫 트립을 실시간으로 보여주고, 주차하면 엔진오일 주기가 가혹으로 바뀌는 브리핑
2. 브리핑에서 `정비 계획 추가` → 정비 권장 화면에 경유 계획 표시
3. 정비 기록 → `말하기` 또는 정비소 확인 QR
4. 판매 준비 → 기록 완성도와 패스포트 QR → `인계 모드 켜기`
5. 인계 모드에서 질문 선택 → `명의 이전 완료`
6. 설정 → 시연 상태로 초기화 후 `고속도로 출퇴근 1주` : 일반 주기 유지 브리핑

시연 주행으로 만든 트립은 `simulated` 로 표시되고 화면에도 시뮬레이션으로 나옵니다.

## 남은 작업

- 엔진오일 외 항목(변속기 오일, 에어클리너, 에어컨 필터) 주기를 차종 매뉴얼 표로 재확인
- NaviHelper 경유지 연동, Pleos TTS/STT 적용
- 케어 패스포트 웹 페이지, 정비사 확인 페이지
- 실제 운전자 주행 기록으로 판정 기준 검증
